# Philippine compliance and accounting configuration notes

This is an implementation boundary, not legal or tax advice. Do not assume a universal tax rate, filing deadline, return version, invoicing rule, or CAS registration status. Before enabling production calculations or submissions, qualified Philippine tax/accounting professionals must validate applicable current BIR issuances and the taxpayer's actual registration and system circumstances.

Tax rules must be data-driven, effective-dated, versioned, approval-controlled, and traceable to their source and reviewer. Preserve the exact configuration version used by each filed or posted transaction. Keep preparation, review, approval, payment, submission evidence, and GL reconciliation as distinct states.

The CAS workstream should assess applicable CAS/CBA registration, notification, certification, invoicing, books, retention, access, change-control, backup, and audit-trail requirements. The system must never describe itself as BIR-approved, BIR-accredited, or compliant by default. Configuration and change histories, sequential document references, source traceability, period locks, immutable posted records, and data-integrity checks are planned controls, not evidence of approval.
